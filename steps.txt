🌟 Option A (recommended): Auto-redirect logged-in users from landing → dashboard
Landing is public, BUT logged-in users instantly skip it.

Feels smooth. Professional. Natural.

Inside app/(public)/page.jsx:

"use client";
import { useEffect } from "react";

export default function Landing() {
  useEffect(() => {
    const token = localStorage.getItem("token");
    if (token) window.location.href = "/dashboard";
  }, []);

  return <YourLandingContent />;
}
